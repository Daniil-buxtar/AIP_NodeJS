# Учебный проект: сервер на Express (Node.js)

Учебный репозиторий по пособию «Проект 2026». В нём собраны два варианта
простейшего сервера на Express — ручной и сгенерированный.

## Ветки

| Ветка | Что внутри | Как запустить |
|---|---|---|
| `manual` (или `web`) | Ручной проект из главы 2.1–2.2: сервер, форма, обработка POST через `body-parser` | `node app.js` → http://localhost:3000 |
| `generator` (или `puh`) | Стартовый проект из главы 2.3–2.4, созданный через `express-generator` с шаблонизатором ejs | `npm start` → http://localhost:3000 |

## Что реализовано

**Ручной проект (ветка `manual`):**
- простейший сервер на Express;
- HTML-форма, отправляющая POST-запрос на `/submit_result`;
- приём данных формы через `body-parser`;
- вывод полученного текста обратно в браузер;
- обработка пустой строки.

**Сгенерированный проект (ветка `generator`):**
- каркас от `express-generator` с шаблонизатором ejs;
- маршрутизаторы `routes/index.js` и `routes/users.js`;
- шаблоны `views/index.ejs`, `views/error.ejs`;
- статические файлы в `public/`;
- переменная среды `env` (`development` / `production`);
- модуль `debug`.

## Установка и запуск

```bash
# клонировать репозиторий
git clone <адрес-репозитория>
cd <папка-репозитория>

# переключиться на нужную ветку
git checkout manual      # или generator

# установить зависимости
npm install

# запустить
node app.js              # для ручного проекта
npm start                # для сгенерированного проекта
